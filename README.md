
# Tech News - Portal de Notícias

Um portal moderno de notícias focado em tecnologia, com seções dedicadas a tópicos como Inteligência Artificial, Blockchain, Internet, Realidade Virtual e muito mais.

## 🎯 Características

- **Layout Responsivo**: Design moderno com grid layout
- **Navbar Interativa**: Navegação principal com busca e categorias
- **Seção Hero**: Destaque de notícia principal com imagens de alta qualidade
- **Cards de Notícias**: Conteúdo organizado em cards com tags categorizadas
- **Design Dark Mode**: Interface escura com cores de contraste (azul e cinza)
- **Tipografia Premium**: Fontes Archivo Black e Archivo do Google Fonts

1. **Header**: Menu de navegação e categorias
2. **Hero**: Notício principal destaque
3. **Mais Lidas da Semana**: Grid de 4 cards destacados
4. **Destaques IA**: Seção exclusiva de Inteligência Artificial com artigos completos
5. **Design Responsivo**: Adaptado para todos os tamanhos de tela (mobile, tablet e desktop)
6. **Categorias Dinâmicas**: Seções temáticas para diferentes áreas de tecnologia
